# Principles

**Dark first.** Jazzfolio is a night out. The page stays dark in both color schemes. Raised surfaces are only a few steps lighter than the background.

**One electric blue.** Primary actions, dates, live state, and focus all use the same accent. Do not add a second brand color.

**Sentence case always.** Write "Late set at SFJAZZ." Do not force titles into uppercase.

**44px touch targets.** Follow, like, save, share, and other jazz actions are at least 44px. Do not shrink them to squeeze a row.

**Tokens, not hex.** Use `bg-primary`, `text-muted-foreground`, `rounded-poster`. If a color is missing, add it to the design system. Do not paste a hex into the app.
