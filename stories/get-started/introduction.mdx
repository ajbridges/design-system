# Introduction

This is the design system for Tony's apps. It is a shadcn registry: tokens, components, and the rules for using them.

It is for designers and engineers building product UI in the same code. Start from these components. Do not redraw a button, a badge, or a card in the app.

**Jazzfolio** is the dark theme for live-jazz discovery. The page is near-black. One electric blue does the work of a primary action, a date, a live state, and a focus ring. Display type is Barlow Condensed, in sentence case. Body type is Inter.

Install the theme and the jazz components together:

```bash
npx shadcn@latest add ajbridges/design-system/jazz#v0.2.0
```

The neutral theme is still available from the toolbar if you are working on the original system. `starter#v0.2.0` installs that system without Jazzfolio.
