# What's new

## v0.2.0

Jazzfolio, a dark-only theme. Near-black surfaces, white and grey text, and one accent, electric blue. Hover and pressed fills keep near-black button labels at WCAG AA. White on that blue does not.

Display type is Barlow Condensed, in sentence case. Body is Inter. Poster corners are generous. Buttons are pills.

Gradients run an artist color or an image into black.

New `jazz` bundle, separate from `starter`: date badge, ticket status pill, follow button, like button, save button, event card, feed post, and calendar month. They stack on a phone and become rows or a month grid on a wide screen. Actions are at least 44px.

Fixes: carousel and the mobile hook no longer set state inside an effect. Button gains touch sizes. Badge gains a live variant.

`v0.1.0` is unchanged.

## v0.1.0

The first registry. Neutral and blue theme, status badges, and the shadcn component set on Base UI.
